# Блог b2b Просебя — прототип нового дизайна

Живой прототип b2b-блога [prosebya.ru/blog-b2b](https://prosebya.ru/blog-b2b) перед переездом с Tilda на WordPress. Все 36 статей перенесены с текущего сайта и свёрстаны в новом дизайне.

**Посмотреть:** https://leratk22.github.io/prosebya-blog-b2b/

## Что внутри

| Страница | Что показывает |
|---|---|
| `index.html` | Листинг: чипы категорий, 12 карточек на страницу, «Показать ещё». Категория — `index.html?cat=<slug>` |
| `blog/<slug>.html` | 36 статей: оглавление, прогресс чтения, таблицы, источники, CTA, похожие статьи |
| `article-blocks.html` | Витрина блоков статьи: ключевые цифры, выноска, таблица сравнения |
| `card.html` | Карточка статьи и её состояния |

Дизайн-система и макеты — в Paper, спецификация и аудит — в документе проекта.

## Как запустить локально

Шрифт подключается файлами, поэтому страницы нужно открывать через сервер, а не двойным кликом:

```bash
python3 -m http.server 4317
```

и открыть http://localhost:4317/

## Устройство

```
assets/blog.css   токены (как в Paper) и все компоненты
assets/blog.js    карточки, «Показать ещё», шапка, мобильное меню, оглавление, копирование
assets/posts.js   список статей: заголовок, анонс, дата, категория, обложка, время чтения
content/raw/      тексты статей с Tilda как есть
content/meta/     SEO-заголовок и описание каждой статьи с Tilda
tools/            скрипты переноса и сборки
fonts/            Euclid Circular A (лицензия Просебя)
```

Пересобрать статьи после правок шаблона или сборщика:

```bash
python3 tools/fetch_articles.py   # забрать тексты с сайта (скачивает только недостающие)
python3 tools/build.py            # собрать blog/*.html по шаблону tools/article-shell.html
```

## Для переноса на WordPress

- **Адреса.** В прототипе `blog/<slug>.html`, на сайте — `/blog-b2b/<slug>/`. Слаги совпадают с текущими, редиректы не нужны.
- **SEO.** `<title>` и описание каждой статьи на Tilda отличаются от H1 и анонса — они лежат в `content/meta/<slug>.json`, их нужно перенести в поля SEO-плагина.
- **Пагинация.** «Показать ещё» — обычная ссылка на `/page/N/`; скрипт перехватывает клик, дописывает карточки и меняет адрес через `history.pushState`. Прямой заход на `/page/N/` должен отдавать эту страницу целиком.
- **Движение.** Все длительности декоративных анимаций умножаются на `--motion-scale` в `blog.css` (сейчас 5 — медленная версия по решению дизайнера). Нажатие не замедляется. При `prefers-reduced-motion` остаются только плавные появления.
- **Обложки.** В прототипе берутся с CDN Tilda в WebP. На WordPress — стандартные размеры миниатюр в WebP.

## Что нашлось в контенте при переносе

- **Лид дублируется.** В 13 статьях первый абзац дословно повторяет анонс — при сборке он убран.
- **Рамки на обложках.** У 11 обложек вшита кремовая рамка (`framed: true` в `posts.js`) — в прототипе обрезана приближением, файлы нужно заменить.
- **Таблицы без шапки.** У всех 4 таблиц нет строки заголовка — это видно и на текущем сайте.
- **Реклама в конце статьи.** Последний раздел каждой статьи — реклама Просебя, в прототипе он стал CTA-блоком.
- **Черновые тексты.** Описания пяти категорий (кроме «Текучести и выгорания») — черновики, нужны тексты редакции.
- **Заглушки.** Ссылки на App Store, RuStore и Google Play в подвале пока заглушки.
